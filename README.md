# 🌐 Welcome to RevConnect

RevConnect is a **full-stack monolithic social media web application** developed as part of the **Revature Training Program (Phase 2)** by the **PES Mandya Batch**.

The platform enables **Personal Users, Content Creators, and Business Accounts** to connect, share posts, build networks, and interact using enterprise-level backend architecture and secure authentication.

🔗 Organization: https://github.com/RevConnect-P2

# 🏗️ Architecture & Design

✨ Enterprise-Level System Design:

- 🧱 Layered Monolithic Architecture  

- 🎯 MVC (Model-View-Controller) Design Pattern  

- 🔐 Spring Security Authentication & Role-Based Access  

- 🗄️ Oracle Database Integration  

- 🧾 PL/SQL Stored Procedures  

- 🔗 JDBC & Hibernate ORM  

- 📊 Logging & Exception Handling  

- 🧪 Unit Testing using JUnit & Mockito  

- 📈 Enterprise-Level Code Structure
